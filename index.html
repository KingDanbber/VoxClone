Acerca de VoxClone

Aplicación web modular (HTML + CSS + JS) para clonación de voz, TTS y voz a voz. Diseñada para ser moderna, profesional y adaptable a cualquier dispositivo.

v1.1.0 · PWA · Neural-ready

Motores recomendados para español latino:
• XTTS v2 (Coqui) — excelente zero-shot, 17 idiomas, acento según muestra (México, Argentina…)
• Chatterbox Multilingual — finetunes específicos LatAm / España, alta naturalidad
• VoxShot + Transformers.js — 100 % en el navegador (WebGPU)
El acento mexicano / latino se obtiene principalmente con una muestra de voz de esa región.
